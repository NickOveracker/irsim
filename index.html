Commands

Type IRSIM commands below, as at its irsim> prompt. A few to start with:

h A · l A · x A
Drive node A high, low, or release it (X)
s · s 50
Step one step, or 50 ns
vector a A B C
Make a vector (bus), most significant bit first; set a 101 drives it
ana A B a
Show nodes and vectors in the analyzer (also w, watchnode)
clock C 0 1 · c
Define a clock and run a cycle
d A a · t A
Print values now; print every change
@ file.cmd
Run a command file
help
All commands

Up and Down recall earlier commands. A command that runs too long can be stopped with Stop: IRSIM starts again and replays everything before it, which gives back the same state.

Analyzer

Right-drag, Shift-drag
Delta marker; z then zooms to the marked interval
Middle click, Esc
Clear the markers
← → · Shift+← →

Names
Click selects (Base applies to it), drag reorders, ✕ removes
Slider
Click or drag centres the view; right-drag or Shift-drag moves an edge

Projects

Project > Open files or Open folder copies .sim, .prm and .cmd files, or one .zip / .tar.gz, into the page; you can also drop them on it. IRSIM starts with the project's .prm (or the built-in scmos100) and its .sim file, then runs the .cmd file with the same name, if there is one. Project > Simulation setup chooses other files.

To keep your work, work in a folder on disk (Chrome, Edge and other Chromium browsers) or keep the project in browser storage (any browser): files IRSIM writes (logfile, dumph, wnet…) and your edits in the Files window are saved there. Otherwise files live in memory until you download them.
