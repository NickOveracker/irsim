The 4-bit counter from Magic's tutorial 11 ("Using IRSIM and RSIM with Magic").

  tut11a.sim   extracted by the Magic web app (https://magic.stixu.io, demo tut11a)
               from tut11a.mag in Magic's src/doc/tutcells/, under Magic's licence (LICENSE in this folder)
  tut11a.cmd   the tutorial's IRSIM command file, from the same folder, unchanged
  counter.cmd  written for the web app: resets the counter, then counts 8 cycles
